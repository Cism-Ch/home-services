# Module: Frontend & User Interfaces

> Anti-Bloat Rule: This module must NEVER exceed **80 lines**.

- [R-UI-01] Mobile-First & Standard Breakpoints: Write base classes for `< 640px` (`grid-cols-1`, `flex-col`), then scale with `sm:`, `md:`, `lg:`, `xl:`. Never invent undefined Tailwind v4 breakpoints (such as `xs:`).
- [R-UI-02] Canonical Full-Width Containers: Put background colors, gradients, and `overflow-hidden` on an outer `<section className="w-full ...">`, and wrap content in `<div className="w-full max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">` (`max-w-4xl`/`max-w-6xl` for reading/checkout). Never use Tailwind `container` without `mx-auto px-4`, and center auth pages with flex (`w-full max-w-[420px]`), never asymmetrical `grid` wrappers.
- [R-UI-03] shadcn/ui v4 Card Rhythm: `Card` enforces `py-6 gap-6` internally. Wrap any direct `<form>` inside `<Card>` with `className="flex flex-col gap-6"`. Use `py-0 gap-0` on image-top or `p-0` split cards (`overflow-hidden`), and never stack custom `pt-8 pb-8` / `p-6` on top of default `CardContent` padding.
- [R-UI-04] Responsive Overlays (Dialog, Sheet, Drawer): Prefix widened `DialogContent` widths with `sm:` (`sm:max-w-lg max-h-[90vh] overflow-y-auto`, keeping `p-4 sm:p-6`) and give every mobile `SheetContent` explicit horizontal/vertical padding and `overflow-y-auto`.
- [R-UI-05] Intrinsic Sizing & Overflow Prevention: Never use unprefixed `min-w-[>=150px]` or fixed `w-[>=240px]` on mobile; prefer `w-full sm:w-auto sm:min-w-[...]`. Always use `grid-cols-1 min-w-0` on stacked mobile CSS Grids (never bare `grid` with `truncate` / `nowrap` descendants) and `min-w-0 [overflow-wrap:anywhere]` on flex children holding headings, emails, addresses, or badges; use `hidden` (never `sr-only` on `w-full` `Input`) for programmatic file inputs. Size calendar sidebars at `>= 300px` (`xl:grid-cols-[310px_minmax(0,1fr)]`) with `overflow-x-auto`.
- [R-UI-06] Equal-Height Grid Alignment: Give sibling grid cards `flex flex-col h-full`, expand `CardContent` with `flex-1`, and push actions cleanly into `CardFooter` (`mt-auto`) so card bottoms align identically.
- [R-UI-07] Negative Overlaps Without Layout Voids: Use negative margins (`-mt-12 md:-mt-16`) rather than `relative -top-*` so collapsed space does not leave blank vertical voids below overlapping headers.
- [R-UI-08] 100% shadcn/ui & Zero Raw HTML Controls: Never write raw `<button>` or `<input>` outside `src/components/ui/` and `src/emails/`, always import `cn` from `@/lib/utils` (never `"cn"`), add `aria-label` to every icon-only button, and keep hover actions visible on touch screens (`opacity-100 sm:opacity-0 sm:group-hover:opacity-100`).
- [R-UI-09] Multi-Theme Parity (Light / Dark / Luxury): Bind `@custom-variant dark` to `.dark` and `.luxury` so Tailwind `dark:` utilities, semantic `Badge`, and `Alert` variants maintain accessible contrast in every theme.
- [R-UI-10] Next.js Smooth Scroll Discipline: Keep `data-scroll-behavior="smooth"` on root `<html>` alongside `@media (prefers-reduced-motion: reduce)` safeguards.
- [R-UI-11] Visual State Coverage & Touch Targets: Systematically handle loading (`Skeleton`), error (`Alert`), empty, and populated states, with interactive controls sized `>= 44px` on mobile.
- [R-UI-12] Multi-Viewport Geometry Verification: Verify live rendered geometry via Playwright at `375px`, `768px`, and `1440px` (`scrollWidth <= innerWidth`, header/footer edge alignment, container margins, and overlay bounds) before marking UI work complete.
- [R-UI-13] Flex Separator Containment: `Separator` defaults to `shrink-0 w-full`; never place raw `<Separator />` siblings inside a horizontal `flex` row without `flex-1` or an `absolute inset-0 flex items-center` wrapper behind a centered label.
